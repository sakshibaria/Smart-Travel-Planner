# Smart Travel Planner ✈️

## Problem
Current travel platforms do not optimize multi-modal routes involving nearby airports and ground transport.

## Solution
A system that compares flights from nearby airports combined with buses, trains, and cabs to find optimal routes.

## Tech Stack
- FastAPI (Backend)
- Streamlit (Frontend)
- Graph Algorithms (Dijkstra, A*)
- External APIs (Flights, Maps)

## Features
- Nearby airport detection
- Multi-modal route planning
- Cost & time optimization
